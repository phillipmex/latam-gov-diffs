What you get

An invite to a private GitHub repository that carries the same nightly diff stream for this one table. A repository, not an endpoint.

  • The diff twelve hours early. The harvest runs at 06:15 UTC and commits to your private repository in the same run; the public archive is pushed at 18:15 UTC. That is a head start on this repository's publication, not on the NF-e portal's - it publishes to everyone at once.
  • Every version and every diff since 2024-12-07, seeded into the repository on day one: the stored table for each release, and the row-by-row comparison between each pair of neighbours.
  • An alert that comes to you. Watch the repository and GitHub emails you, or pushes to your phone, on any night that produced a change. A night with no change produces no commit and no noise.
  • A changes.json written for machines. One file to poll: the latest version pair, the added / changed / removed counts, which columns appeared and disappeared, and the path to the full diff. Compare one field with the id you last processed and stop if they match.
  • Somebody to ask. Open an issue in your own repository; first response within two business days.

What is not included

  • No hosted API. No endpoint, no key, no query language. You clone a git repository.
  • No webhooks. Nothing calls your server; GitHub notifications and changes.json are the two ways you find out.
  • No SLA. Best effort, nightly, on free hosted runners. If the portal is down that night produces nothing.
  • No exclusivity. The free archive keeps everything, twelve hours behind.
  • No custom columns and no per-customer parsing at this price.

What the diffs actually caught

Three examples, taken from the stored summaries. Each one is a day on which a mapping built against the previous release stopped being complete:

  • 2026-04-15 → 2026-06-23 Six new columns appeared at once - regulamento_ibs, regulamento_cbs, tprbsn, ind_gpbiodiferenca, inddir and indduimp - and eight new codes with them. Every one of the 156 existing rows reads as changed, because every one of them gained values it did not have before.
  • 2024-12-07 → 2025-05-06 The article references were restructured: lc and lc_redacao were dropped and lc_214_25 and lc_214_25_2 took their place, with 43 codes added and 12 removed. Anything keyed on the old column names stopped resolving.
  • 2025-11-24 → 2025-12-15 No code was added or removed and the row count did not move - but ind_redutorbc was dropped, so all 132 rows that carried it read as changed. A release that looks like a no-op in the row count is not one.

Description rewrites are the quiet ones: descricao_cclasstrib moved on 82 records in the first diff and on 11 more in the 2025-12-15 release, with no change to any code.

How delivery works

  1. You pay, and give a GitHub username. A private repository is created for you and seeded with the whole cclasstrib history: every stored release, every diff, and changes.json.
  2. GitHub sends you the collaborator invite. There is no message from us, no onboarding call, and no address to hand over.
  3. Each night at 06:15 UTC the harvest runs. If the portal published a new table, the diff is committed to your repository there and then. If it did not, nothing is committed.
  4. You are notified by GitHub, or your code polls changes.json and sees a new version id.
  5. If you cancel, the invite is revoked at the end of the period already paid for. The free archive is still there, twelve hours behind, with everything in it.

Questions

Can I get this history somewhere else?

Yes, in part - and it would be dishonest not to say so. The NF-e portal keeps its back versions of the table online, so the individual releases are downloadable without us. What is not available anywhere is the comparison: which rows moved, which columns appeared, which descriptions were rewritten, per release, already computed. That is what you are paying for. The archive is the insurance; the diff is the product.

Who is this for?

Developers who maintain an NF-e or IBS/CBS classification mapping - a lookup from your product or service catalogue to a cClassTrib code, and from there to the fields the fiscal document needs. If that mapping exists in your codebase, this feed tells you what to check before your next release rather than after a rejected document.

What actually breaks in my mapping?

Four things, in rising order of how long they take to find. A new code appears and your fallback silently mis-classifies it. A code is removed and your mapping still points at it. A column is added or dropped, and a reader that assumes a fixed layout either misses a required field or throws. And the quietest one: a description or an article reference is rewritten with no code change at all, so anything that matched on text rather than on the code stops matching - with nothing in the row count to tell you.

What happens if the portal changes the file format?

That night's harvest produces nothing rather than producing something wrong, and the issue tracker says so. The parser is fixed as fast as it can be fixed, and the backlog is caught up from the stored file, so no release is lost. There is no SLA and no credit - the honest description is best effort, nightly.

Is this an API?

No. It is a private git repository with files in it, plus GitHub's own notifications. There is no endpoint to call, no key to rotate, and nothing of yours to configure. That is a deliberate limit, not a stage on the way to something else.

What happens when I cancel?

Access runs to the end of the period you have paid for, then the collaborator invite is revoked and the private repository is archived. Nothing is clawed back: anything you cloned stays cloned, and every diff you were sent is still yours. The public archive keeps publishing, free, twelve hours behind.

Why should I pay when the archive is free?

Often you should not, and the free tier is genuinely the right answer for most readers. Three things are behind the price and nothing else: the diff twelve hours earlier, an alert that reaches you instead of you remembering to look, and somebody to ask when a row makes no sense. If none of those three is worth $28 a month, use the free viewer - it is not a trial and it is not reduced.
