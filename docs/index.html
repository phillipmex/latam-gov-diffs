Nightly archive and diff of Latin American government reference data. Free to read; the paid feeds and attestations add a twelve-hour head start, an alert and somebody to ask.

Three feeds, archived nightly

Each source is fetched every night, stored as a dated snapshot, and compared with the version before it. Pick a feed to see everything it has recorded.

Subscribe to the changes

Every revision of every feed, newest first, as an Atom feed any reader can follow. Nothing to install and no account.

Atom feed - all feeds CHANGES.md - the same thing to read

How to use it

Read it in a browser
This page. Every view is a link you can bookmark or paste to a colleague.
Poll it from a script no install
Fetch the index, then the diff file it names. Plain HTTPS, no key, no account. https://raw.githubusercontent.com/…/docs/index.json
Python available from launch
pip install govdiff - the harvester: fetch, snapshot, diff, index.
Node available from launch
npm install govdiff - a zero-dependency reader for the published archive, or npx govdiff feeds with no install at all.
